# G9 Tabletop Game Design — Task Sheet Contents

Working contents for the sixteen student task sheets, one per MYP Design strand. Fill this in and revise it here, then the sheets get built from it. Sheets are A4 landscape, printable as a set, and each one also loads as an expandable card under its task on [g9-game-design.html](../g9-game-design.html).

Layout is **Three Acts**: a masthead carrying the MYP framing, then three columns headed **Do**, **Hand in** and **Graded**, then a band of four tips along the foot. Every heading below maps to a slot on the sheet.

## How to read this file

| Marker | Means |
|---|---|
| `TO WRITE` | Nothing exists yet. Needs writing before the sheet can be built. |
| `FROM PAGE` | Pulled from the unit page as-is. Revise the wording into the second person. |
| `CHECK` | Exists but is questionable. Read the note. |

Everything on the unit page is written for a teacher: *Students develop a range of ideas*. Every line that reaches a sheet needs the second person: *You will develop a range of ideas*. That rewrite is assumed throughout and is not marked separately.

## A note on the band lines

The unit page has an `obj-outcome` block on eight strands, but only **Ai** and **Aiii** actually describe a band boundary. The other six are teaching notes about the task rather than the difference between a 5-6 and a 7-8. All sixteen ladders below are therefore blank, with the existing note quoted underneath wherever there is one worth reusing.

The 7-8 row is the MYP descriptor itself, which is quoted verbatim under **Graded** on each sheet. Write the three rows below it as what is *missing* at that level, in plain language a Grade 9 can act on.

### Hand in

- Submit to **Upload pictures of your page on ManageBac, and submit the actual paper in class.**

### Graded

MYP descriptor, quoted verbatim on the sheet:

> Explains and justifies the need for a solution to a problem for a client/target audience.

| Band | What it looks like | |
|---|---|---|
| 1-2 | | An incomplete statement with limited notes, no justification, and no explanation. |
| 3-4 | | A need statement and audience notes, with limited justification and explanation. |
| 5-6 | | A need statement and audience notes, with some justification and explanation. |
| 7-8 | | A detailed need statement and audience notes, with strong justification and clear explanation. |

### Tips

Four to a sheet, along the foot band. Keep each to roughly twenty words.

1. You must write your own need statement and audience notes. No sharing at all!
2. Don't make assumptions, ask questions to find evidence.
3. Justifying the need for something means explaining why it is needed in detail, with proof.
4. Writing about something you want or care about is a not acceptable.

Possible sources on the unit page, failures already written up: *Writing about themselves*; formatives that could become advice: *Need or want sort*, *Weak brief autopsy*.
