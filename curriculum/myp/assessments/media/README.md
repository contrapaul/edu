# Card images

`aiii-builder.webp` is the featured image on the Aiii tool card on the
G9 unit page. Any aspect ratio works; the card crops to 4:3 from the top,
so put the important part of the screenshot at the top of the image.

Drop the file here and it appears. No code change is needed. Until it
exists the card shows a hatched placeholder instead of a broken image.
