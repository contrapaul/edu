Printable sheets / one A4 side per mechanic

Colour coded by family so a wall of them groups by type. The set opens with a poster, which prints sideways on a portrait sheet so the whole set is one orientation, then family title pages, two to an A4 side, to be cut in half and used as dividers. The diagram runs the full width. Links, photos, the tag row and "try this" are left off to keep every mechanic on a single side.

Each family has a band colour, used for the header, the page border and the accents, and a tint used behind the diagram and the game panels. Changes are kept in this browser and are used when you print.
