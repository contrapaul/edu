Card Style Catalog

Every .tool-card style in one place — the ones already running on the tools page, the ones that only ever existed in the two showrooms, and a set of new ones. Each entry is a live card next to the exact CSS and HTML that produce it.

To use one in tools/index.html:
  1. Copy the CSS block and paste it inside the <style> element in the page head.
  2. Copy the HTML block into <div class="tool-cards-grid">, then swap the href, title and subtitle for the real tool.
  3. Tune the colours through the inline custom properties — --card-title-color, --card-sub-color, --card-title-size, --card-bg, --card-border, --card-font. The base .tool-card layout (360×200, centred, flex column) comes from style.css and does not need copying.
  4. Two styles need a one-time script; those entries include it as a third block.
  5. Photographic styles carry real artwork. Three take it as a --card-img custom property next to the colour ones; two use an <img class="cs-shot"> so the picture can hold alt text. Paths are relative to tools/, so they work unchanged in tools/index.html — the demo images are borrowed from the curriculum folders, so point them at your own artwork.
